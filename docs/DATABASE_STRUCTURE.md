# Database Structure

CivicPulse Engine uses Supabase PostgreSQL. The repository defines 19 application
tables, excluding Supabase-managed authentication tables. This inventory reflects
the schema snapshot, migrations through 015, and application queries; it is not a
fresh inspection of the deployed database. The local bootstrap reconstructs older
production tables and differs from the snapshot in some legacy columns.

## Table 6 — Data Pipeline Tables

| Table               | Primary Key | Key Attributes                                                                                                                                                                                                                                       | Purpose                                                                                                                                              |
| ------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `raw_content`       | `id`        | `source_platform`, `source_page_id`, `post_id`, `comment_id`, `raw_text`, `author_hash`, `created_at`, `fetched_at`, `is_processed`, `reaction_count`, `reply_count`                                                                                 | Stores anonymized public content from supported platforms. The active ingestion script collects YouTube comments; the schema also supports Facebook. |
| `processed_content` | `id`        | `raw_content_id`, `content_type`, `cleaned_text`, `language`, `hashed_user_id`, `sentiment_label`, `sentiment_score`, `sentiment_needs_review`, `topic_label`, `topic_score`, `topic_needs_review`, `is_flagged`, `barangay_mention`, `processed_at` | Stores NLP analysis and review indicators. The production snapshot also includes `comment_id`; the local bootstrap includes `created_at`.            |
| `flagged_claims`    | `id`        | `processed_content_id`, `matched_document_id`, `matched_chunk_id`, `claim_text`, `matched_patterns`, `rag_determination`, `rag_evidence_snippet`, `status`, `language`, `source_platform`, `created_at`                                              | Stores potentially false claims and their retrieved evidence. The production snapshot additionally includes `similarity_score` and `comment_id`.     |

## Table 7 — Civic Issue Tracking Tables

| Table                      | Primary Key | Key Attributes                                                                                                                                                                                                | Purpose                                                                                                                       |
| -------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `civic_issues`             | `id`        | `title`, `description`, `source_comment_id`, `source_flagged_claim_id`, `topic`, `priority`, `status`, `assigned_to`, `created_by`, `created_at`, `updated_at`, `resolved_at`                                 | Tracks civic concerns, assignments, priorities, and resolution status. `source_comment_id` references `processed_content.id`. |
| `issue_comments`           | `id`        | `issue_id`, `author_id`, `body`, `created_at`                                                                                                                                                                 | Stores internal staff discussion.                                                                                             |
| `issue_status_logs`        | `id`        | `issue_id`, `changed_by`, `from_status`, `to_status`, `note`, `changed_at`                                                                                                                                    | Records status transitions.                                                                                                   |
| `issue_resolution_rounds`  | `id`        | `issue_id`, `round_number`, `submitted_by`, `resolution_summary`, `actions_taken`, `observed_outcome`, `evidence_links`, `status`, `submitted_at`, `decided_at`                                               | Stores resolution evidence submitted for peer review.                                                                         |
| `issue_resolution_reviews` | `id`        | `round_id`, `reviewer_id`, `decision`, `actions_completed`, `evidence_sufficient`, `outcome_addresses_issue`, `no_unresolved_blocker`, `comment`, `assigned_at`, `due_at`, `submitted_at`, `reminder_sent_at` | Stores three blind reviewer evaluations; resolution requires a two-of-three majority after all votes are submitted.           |

## Table 8 — Review and Knowledge Base Tables

| Table             | Primary Key | Key Attributes                                                                                        | Purpose                                                                                                                                                                                                                              |
| ----------------- | ----------- | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `review_records`  | `id`        | `flagged_claim_id`, `reviewed_by`, `decision`, `notes`, `reviewed_at`                                 | Records human verification decisions on flagged claims.                                                                                                                                                                              |
| `lgu_documents`   | `id`        | `uploaded_by`, `document_type`, `title`, `content`, `uploaded_at`, `is_active`                        | Stores official documents across 13 document categories. The legacy production `embedding` column is removed only when cleanup migration 007 is applied; this inventory does not certify the migration state of a deployed database. |
| `document_chunks` | `id`        | `document_id`, `chunk_index`, `chunk_text`, `section_label`, `token_count`, `embedding`, `created_at` | Stores document sections with 768-dimensional embeddings for the active chunk-level RAG retrieval path.                                                                                                                              |
| `nlp_categories`  | `id`        | `name`, `description`, `created_by`, `created_at`                                                     | Stores civic-topic reference categories.                                                                                                                                                                                             |

## Table 9 — Notification and Trend Monitoring Tables

| Table                    | Primary Key                         | Key Attributes                                                                                                                 | Purpose                                                                    |
| ------------------------ | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------- |
| `notifications`          | `id`                                | `user_id`, `category`, `severity`, `title`, `body`, `href`, `entity_type`, `entity_id`, `fingerprint`, `read_at`, `created_at` | Stores private trend and issue peer-review notifications.                  |
| `notification_prefs`     | `user_id`                           | `in_app`, `email`, `categories`, `updated_at`                                                                                  | Stores notification channel and category preferences.                      |
| `notification_snapshots` | (`user_id`, `window_days`, `topic`) | `score`, `rank`, `negativity`, `comment_count`, `captured_at`                                                                  | Stores per-user topic baselines for 7-, 30-, and 90-day trend comparisons. |
| `trend_alert_eval_state` | `id`                                | `last_evaluated_at`                                                                                                            | Stores the singleton throttle for system-wide trend evaluation.            |
